# MeetIQ – AI-Powered Meeting Analysis System

MeetIQ is an AI-powered meeting assistant that converts meeting recordings into searchable and structured insights.

## Features

- Audio and video file uploads
- YouTube URL support
- Audio extraction using FFmpeg
- English transcription using OpenAI Whisper
- Hindi/Hinglish transcription using Sarvam AI
- AI-powered summaries using Google Gemini
- Action item extraction
- Key decision identification
- Open question extraction
- Conversational meeting Q&A using RAG
- FAISS vector search

## Technology Stack

- Python
- Streamlit
- Google Gemini
- OpenAI Whisper
- Sarvam AI
- LangChain
- Hugging Face Embeddings
- FAISS
- FFmpeg
- yt-dlp

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```
